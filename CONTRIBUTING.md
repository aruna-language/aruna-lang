# Contributing

Aruna is in early development. Before contributing:

1. **Do not invent Madurese vocabulary or grammar.** Language decisions belong to the creator (Iky Dev). Propose changes in an issue and label them as proposals.
2. Keep the compiler independent of specific words: vocabulary lives in `keywords/`.
3. Every feature needs tests in `tests/`. Run `npm test` before opening a pull request.
4. Keep documentation honest: do not describe unfinished features as implemented.
5. Avoid new dependencies unless there is a strong reason.
