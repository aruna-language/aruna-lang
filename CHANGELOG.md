# Changelog

## [0.1.0] - Early Preview (unreleased)

### Added
- Lexer, parser, static type checker with inference and nullable safety, tree-walking interpreter.
- CLI commands `run`, `check`, `--version`, `--help`.
- Provisional vocabulary profile (`keywords/provisional.js`) and an empty approved profile slot (`keywords/approved.js`).
- Examples, documentation and an automated test suite.

### Notes
- Vocabulary is provisional and not Madurese.
- No license chosen yet.
