# Roadmap

Draft; may change.

1. **v0.1.0 (this release):** working core with provisional syntax.
2. **v0.2.0:** approved Madurese vocabulary and grammar; examples and docs rewritten with it.
3. Lists/collections, `for` loops, string interpolation.
4. Structs and methods; basic modules.
5. Syntax-highlighting grammar; editor plugins (Acode, VS Code).
6. Bytecode VM and performance work.
7. Learning levels (Junior, Junior+, Advanced, Developer) on top of one core.
8. Browser playground using the same interpreter; package distribution (pip, npm) and installers.
