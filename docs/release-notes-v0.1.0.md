# Aruna Programming Language v0.1.0 — Early Preview

First public development milestone. This is an early preview and may contain experimental features. It is not production-ready.

## Highlights

- A real pipeline: lexer, parser, static type checker, interpreter
- Static typing with inference and safe nullable types (`T?`, `??`, narrowing)
- Variables, arithmetic, strings, `if`/`else`, `while`, typed functions with recursion
- Clear diagnostics with positions, excerpts and hints
- CLI: `run`, `check`, `--version`, `--help`, with documented exit codes
- 96 automated tests

## Important

- Keywords are **provisional placeholders, not Madurese**. See [open-decisions.md](open-decisions.md).
- No LICENSE has been chosen yet.
- Tested on Node.js v22 / Linux only.
